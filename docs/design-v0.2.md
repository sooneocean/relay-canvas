# v0.2 創作體驗

v0.2 的本機預覽聚焦專案、畫布與素材。沿用 v0.1 的生成服務與 Codex MCP，重新安排創作者每日使用的入口。

## 設計依據

參考 [LibTV 首頁](https://www.libtv.com/) 與官方 [公開作品的唯讀畫布](https://www.libtv.com/detail/4191858cb2c3466c9e3ad960d7583223)。REA 觀察顯示：首頁使用寬側欄、新建畫布與生成入口；唯讀畫布以媒體節點、細連線和浮動控制為主要構成。登入後生成編輯器未觀測，因此 Relay Canvas 的編輯控制依自身能力獨立設計。沒有沿用 LibTV 的程式碼、品牌或作品素材。

REA evidence：首頁 `ev_360ed4dca27032bb2cbf421f9fc9871094df3429c3df9ec86dcec8b33fa6e7d1`；公開畫布 `ev_1be928e48ef4858fe0eede4b09000c428a1dce8e4b7c741328f6222189ec9b5b`。

## 操作結構

- 首頁：新建畫布、圖片／影片入口與真實專案卡片。
- 專案：搜尋、建立、開啟；卡片呈現上次生成結果或空白畫布示意。
- 畫布：媒體優先的節點、浮動新增工具、可收合的生成設定與歷史。
- 素材：從成功執行結果整理的圖像／影片列表，預覽後可回到來源專案。
- Codex：真實 MCP 工具與設定說明，使用同一份可保存畫布。

視覺使用中性黑灰、白色主操作、低對比邊界與適量留白；媒體結果保留主要空間，設定在需要時出現。小視窗以折疊導覽與抽屜調整，不依賴固定三欄。

## 資料與交互界線

Board 沒有更新時間欄位，UI 不製造「最近編輯」時間。專案依最後執行時間排序，沒有 run 的專案保持 store 順序；縮圖使用最近成功執行的第一個產物，並標示為上次生成。沒有結果的專案顯示空狀態。

素材只顯示現存專案的成功 run 中成功節點的 artifacts，依執行時間、節點順序與產物順序排列。Demo 會標記；gallery 不新增媒體下載代理、永久保存或外部生成呼叫。

影片縮圖會等待解碼並擷取開頭的預覽影格，不自動播放。Chromium 的 time-zero 影格可能尚未可擷取，因此先 seek 至 0.1 秒（短片最多取時長的一半）；Demo 瀏覽器檢查同時驗證縮圖有實際像素內容與預覽可播放。

首頁返回、切換專案、素材導覽和建立專案共用保存保護。保存失敗、revision 衝突或保存期間仍有新編輯時，保留原畫面與本機修改，不自動放棄草稿。

這次不加入音訊、剪輯時間軸、社群、會員點數、多人權限或新的供應商協定。遠端費用確認、金鑰隔離與 MCP contract 維持 v0.1 的邊界。此文件描述 v0.2 本機預覽範圍，不表示 v0.2 已公開發布。
