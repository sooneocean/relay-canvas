# Product improvement goal and competitor evidence

The active user goal is v0.4 delivery followed by 1,000 verified product improvement rounds toward competitiveness with LibTV. Publishing v0.4 is not completion of that full goal. The machine-readable ledger is [improvement-ledger.json](improvement-ledger.json).

## Counting a round

A completed round requires a concrete user-visible improvement or a substantive reliability/security improvement, an implemented change, and current verification covering that change. Record the user problem, result, evidence and remaining limits. Do not count research, plans, waiting, repeated checks, autogenerated permutations, version bumps or a numbered backlog as completed improvements. Start this goal's counter at zero; do not retroactively relabel v0.1–v0.3 as rounds of this goal. Group changes by distinct user outcome, not by file or assertion count.
